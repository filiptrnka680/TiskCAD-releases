# TiskCAD – ke stažení

Parametrický CAD pro 3D tisk – česky, offline a s vůlemi podle tvé tiskárny.

**[⬇ Stáhnout nejnovější verzi pro Windows](https://github.com/filiptrnka680/TiskCAD-releases/releases/latest)**

1. Na stránce verze stáhni soubor `TiskCAD_…_x64-setup.exe`.
2. Spusť ho. Pokud Windows napíše „Systém Windows ochránil váš počítač“, klikni na **Další informace → Přesto spustit**.
3. Nové verze ti TiskCAD nabídne sám – stačí kliknout na **Aktualizovat**.

Web: [tiskcad.cz](https://tiskcad.cz) · Podpora: info@tiskcad.cz
